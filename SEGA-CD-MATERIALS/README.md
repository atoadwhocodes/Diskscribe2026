# Sega CD Materials

This folder contains local Sega CD / Mega-CD project materials used with DiskScribe2026.

## Suggested Layout

- `ALSHARK-SOURCE/`: user-supplied original Alshark Sega CD disc image files.
- `ALSHARK-WORKING/`: local extracted or converted working files.
- `ALSHARK-BACKUPS/`: local backup copies created during experiments.

## Supported Local Image Types

Initial investigation can work from common disc image formats such as `.cue` + `.bin`, `.iso`, `.chd`, `.ccd`, `.img`, and `.sub`.

## Distribution Note

These materials are local working assets. Do not include disc images, audio tracks, BIOS/System Card files, extracted source text, cutscenes, voice data, or patched disc images in public releases unless there is a documented legal basis to distribute them.

Public releases should use the clean patch export workflow described in `../LEGAL.md`.
