# PC-98 Materials

This folder contains local PC-98 project materials used with DiskScribe2026.

## Contents

- `ALSHARK-CURRENT/`: current working Alshark PC-98 HDM disk images and build notes.
- `ALSHARK-BACKUPS/`: backup copies of Alshark PC-98 HDM disk images.

## Distribution Note

These materials are local working assets. Do not include disk images, backups, extracted source text, or patched disk images in public releases unless there is a documented legal basis to distribute them.

Public releases should use the clean patch export workflow described in `../LEGAL.md`.
