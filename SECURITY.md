# Security Policy (DiskScribe2026)

## Supported versions
Only the latest version on `main` is supported.

## Reporting a vulnerability
Please do not open a public issue for security reports.

Preferred: GitHub private vulnerability reporting for this repository.

Fallback email: danr@atoadwhocodes.com

Please include:
- affected commit/version
- clear reproduction steps or proof-of-concept
- impact assessment (what can an attacker do)
- any relevant logs/screenshots

## Disclosure
We will acknowledge receipt and coordinate a fix/release. Please allow time for triage and patch validation before public disclosure.
