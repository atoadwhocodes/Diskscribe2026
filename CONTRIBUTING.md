# Contributing

## Prerequisites

- Node.js 22+
- npm 11+
- VS Code 1.90+

## Local Development

```bash
npm ci
npm run compile
npm test
```

Run extension host with `F5` in VS Code.

## Pull Requests

- Keep changes focused and scoped.
- Update docs/changelog for behavior changes.
- Ensure CI passes (`compile`, `test`, `package:vsix`).
